# Security Policy

## Reporting a Vulnerability

If you believe you've found a security vulnerability in this action, please report it privately via [GitHub Security Advisories](https://github.com/vaulted-fyi/share-secret/security/advisories/new).

You can also email **security@vaulted.fyi** if you prefer not to use GitHub.

Please include:

- A description of the issue and its impact
- Steps to reproduce
- Affected versions, if known
- Any proof-of-concept code or logs (please redact secrets)

We aim to acknowledge reports within 3 business days and provide a remediation timeline within 7 days. Please do not open public issues, pull requests, or social media posts for security-sensitive findings until a fix has shipped.

## Supported Versions

Only the latest `v1` major release receives security updates. Pin to `@v1` (or a specific commit SHA) to receive fixes automatically.

## Scope

This policy covers the action code in this repository (`src/`, `dist/`) and its release artifacts. The vaulted.fyi service and `@vaulted/crypto` package have their own security policies in their respective repositories.
